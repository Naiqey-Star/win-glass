# win_glass v1.0.1 修复报告

> 针对上一版安装后「不可用」的两个问题的修复说明
> 平台：Windows x64 ｜ 构建：PyInstaller 6.19.0 ｜ 作者：月见八千代 (Yachiyo)

---

## 一、你反馈的现象与真因

| 现象 | 真因 | 结论 |
|---|---|---|
| 点开始菜单快捷方式，弹出的是记事本，里面是 VBS 脚本内容（`ws.Run "...\win_glass.exe", 7, False`） | v1.0.0 用一个 `.vbs` 当「最小化启动器」，而**这台机器的 `.vbs` 文件关联被改成了记事本** → 双击只是「用记事本打开脚本」，脚本从未被执行 | 不是程序坏了，是启动方式选错了 |
| 直接跑 `win_glass.exe` 会弹一个命令行黑窗口，很丑 | 主程序是 `--console` 构建，且退出/交互依赖控制台（`Ctrl+C`、关闭控制台窗口） | 打包方式从根上就不适合日常双击使用 |

**一句话**：v1.0.0 把「交互」和「启动」都押在了控制台上，而这个方案在你的机器上恰好两头都踩坑。

## 二、v1.0.1 的修复

### 1. 彻底删掉 VBS 启动器

- 安装器不再生成任何 `.vbs`
- 开始菜单快捷方式**直接指向 `win_glass.exe`**（不再经过脚本解释器）
- 升级安装时**主动删除**残留的 `win_glass.vbs`，自动修复你机器上那个坏快捷方式

### 2. 主程序改为窗口化（无控制台）+ 系统托盘

| 项目 | v1.0.0 | v1.0.1 |
|---|---|---|
| 主程序构建 | `--console`（有黑窗口） | `--windowed`（**完全无窗口**） |
| 日常交互入口 | 控制台（Ctrl+C 退出） | 系统托盘图标 |
| 退出方式 | 关闭控制台 | 托盘右键 → 退出 |
| 诊断输出 | 直接在控制台 | 另一份 `win_glass-console.exe` + 日志文件 |

托盘操作：

- **左键单击** = 暂停 / 继续（暂停时所有窗口立刻恢复 100%）
- **右键** = 暂停、立即恢复、打开日志、退出

托盘的窗口是「隐藏的顶层窗口 + `WS_EX_TOOLWINDOW`」，因此**不会出现在任务栏，也不会出现在 Alt+Tab 里**。

### 3. 顺带修掉三个隐藏缺陷

| 缺陷 | 影响 | 修复 |
|---|---|---|
| `shutdown()` 用 `_stop` 判幂等，而托盘退出正是先置 `_stop` | **托盘「退出」时不会还原窗口**，所有窗口卡在 40% 透明度 | 改用独立的 `_shutdown_done` 守卫 |
| 托盘窗口原本建成消息窗口（`HWND_MESSAGE`） | 卸载器用 `taskkill`（不带 `/F`）发 WM_CLOSE 时**收不到**，会被降级成强杀 → 窗口卡在半透明 | 改用隐藏顶层窗口，并新增 WM_CLOSE / 注销 / 关机 的还原处理 |
| `--log` 在窗口化模式下被 import 期的默认日志顶掉 | `--log` 形同虚设 | 目标日志变更时重开文件句柄 |

### 4. 版本号

`1.0.0 → 1.0.1`。安装包文件名、程序文件属性、`--version`、启动日志、控制面板「程序和功能」里显示的版本全部同步。

## 三、安装包信息

| 项目 | 内容 |
|---|---|
| 目标平台 | Windows x64（本机同架构） |
| 包格式 | PyInstaller 单文件自解压安装器（`.exe`，双击即装，无需管理员/UAC） |
| 安装包 | `win_glass_setup_v1.0.1.exe` |
| 输出目录 | `dist\`（`python build.py` 生成） |
| 默认安装位置 | `%LOCALAPPDATA%\Programs\win_glass`（用户目录，不弹 UAC） |
| 安装内容 | `win_glass.exe`（窗口化+托盘）、`win_glass-console.exe`（诊断）、`icon.ico`、`uninstall.exe` |
| 卸载方式 | 控制面板「程序和功能」→ win_glass 窗口透明度，或 `uninstall.exe` |

### 怎么用

1. 双击 `win_glass_setup_v1.0.1.exe`（会覆盖安装，自动清理旧版 `.vbs` 与旧快捷方式）
2. 开始菜单搜 `win_glass` 打开 —— **不会再有任何命令行窗口**
3. 右下角托盘出现图标即在工作：左键暂停/继续，右键退出
4. 想开机自启：`win_glass_setup_v1.0.1.exe --autostart`

> 安装器本身仍是控制台程序（安装过程有文字反馈，属正常现象）。
> 日常使用的 `win_glass.exe` 已完全没有窗口。

## 五、如果你想要更进一步

- 想改未聚焦透明度：`win_glass.exe --inactive-alpha 0.3`
- 想改渐变时长：`win_glass.exe --fade-ms 300`
- 想看当前接管了哪些窗口：`win_glass-console.exe --list`
- 每次状态变化都要打印：`win_glass-console.exe -v`

> 注意：窗口化版没有控制台，`--list`/`-v` 的输出会写进日志（托盘右键 → 打开日志），
> 位置 `%LOCALAPPDATA%\win_glass\win_glass.log`；要看实时输出请用 `win_glass-console.exe`。
